# 21. Proposal Deck Plan
## Format recommendation
Use 16 slides, exported to PDF under 10 MB. This leaves four slides of official headroom but is long enough to cover every required component and the six criteria. Do not use all 20 unless actual evidence requires it. [PDF-PP p. 2]

## Official judging criterion → proposal evidence
| Official criterion | Evidence in proposal |
|---|---|
| Relevance | Official facility modes; July 2026 policy shift; concrete claim-line case; JKN scale without fraud overclaim |
| Creativity/innovation | Claim-to-clinical evidence graph, counter-evidence, reason provenance, human label loop; differentiation table |
| Technology quality | Published-resource mapping; restrained architecture; rules/similarity/anomaly rationale; LLM non-role |
| Effectiveness/impact | Frozen synthetic baselines; FP/100; precision@review budget; latency; pilot measurement plan |
| Readiness/scalability | Actual prototype/screens, clean run, standards-shaped contracts, staged authorized pilot, explicit assumptions |
| Security/governance | Synthetic/pseudonymous data, UU PDP framing, roles, audit, uncertainty, human decision, false-positive case |


## Deck production rules
- One claim per slide; no paragraph walls.
- Source every statistic and policy statement in a readable footer.
- Clearly stamp screenshots/charts SYNTHETIC PROTOTYPE DATA.
- Never show a metric placeholder as a result.
- Use exact category and mode wording from the official documents.
- Use diagrams and screenshots, not stock photos.
- Keep a source/evidence backup appendix in the working deck, but export only the selected 16 slides unless allowed and useful.
